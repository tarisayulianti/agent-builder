# V7 — Cloud Deployment (Docker & Kubernetes)

## Status: 🔲 V7 — Belum mulai (V6 belum dimulai)

## Visi
Deploy agent-builder ke cloud menggunakan Docker dan Kubernetes untuk scaling horizontal, high availability, dan auto-scaling.

## Environment Setup
```bash
# 1. Install Docker & kubectl
# Docker: https://docs.docker.com/get-docker/
# kubectl: https://kubernetes.io/docs/tasks/tools/

# 2. Connect to Kubernetes cluster
kubectl config use-context <your-context>

# 3. Deploy ke cloud (AWS/GCP/Azure)
helm install agent-builder helm/agent-builder/

# 4. Check deployment
kubectl get pods -l app=agent-builder
kubectl get svc agent-builder-svc
```

## Arsitektur V7
```
V7: Cloud (Docker + K8s)
```

## Docker Deployment
```bash
# Build image
docker build -f docker/Dockerfile.agent2 -t agent-builder:v7 .

# Run with Docker Compose
docker-compose -f docker/docker-compose.yml up -d

# Check
curl http://localhost:8080/health
```

## Kubernetes Deployment
```bash
# Deploy ke K8s
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml
kubectl apply -f k8s/ingress.yaml

# Check status
kubectl get all -l app=agent-builder

# Logs
kubectl logs -l app=agent-builder -f

# Scale
kubectl scale deploy agent-builder --replicas=5
```

## Helm Installation (Recommended)
```bash
# Install Helm chart
helm install agent-builder helm/agent-builder/ \
  --set image.tag=v7 \
  --set environment=production \
  --set replicaCount.min=3 \
  --set replicaCount.max=10

# Upgrade
helm upgrade agent-builder helm/agent-builder/

# Uninstall
helm uninstall agent-builder
```

## Auto-scaling
```yaml
# HorizontalPodAutoscaler (auto-generated by Helm)
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: agent-builder-hpa
spec:
  minReplicas: 3
  maxReplicas: 10
  metrics:
  - type: Resource
    resources:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70
```

## Monitoring (Prometheus + Grafana)
- **Metrics endpoint**: `http://<pod>:8080/metrics`
- **Grafana dashboard**: Import dashboard.json
- **Alert rules**: CPU > 80%, Memory > 85%, Queue > 100

## Test Commands
```bash
# Docker health check
docker-compose -f docker/docker-compose.yml run --rm agent-builder python orca.py status

# Kubernetes health check
kubectl exec -it <pod-name> -- python orca.py status

# Load test
helm install agent-builder-test helm/agent-builder/
kubectl get hpa -w
kubectl get events --sort-by=.metadata.creationTimestamp

# Cleanup
helm uninstall agent-builder-test
```

## Note
Docker TIDAK support di Termux — V7 hanya untuk cloud deployment.
V1-V6 berjalan native di Termux/Windows.

## Migration Path (V6 → V7)
1. Containerize orca.py + status_tracker.py + hermes_client.py
2. Set up shared Redis (task queue) dan PostgreSQL (history/status)
3. Deploy ke Kubernetes cluster
4. Configure auto-scaling dan monitoring
5. Set up ingress dengan TLS

## Integration Points
- `docker/Dockerfile.agent2` ↔ semua code files (packaging)
- `k8s/deployment.yaml` ↔ `orca.py` (orchestrator deployment)
- `helm/agent-builder/` ↔ `05-configuration/.env.example` (config template)
- `k8s/` ↔ monitoring stack (Prometheus metrics endpoint)
