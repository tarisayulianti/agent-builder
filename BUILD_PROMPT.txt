# BUILD INSTRUCTION — Agent Calling Agent Builder

## Context
Kamu adalah AI coding assistant yang akan membangun project Agent Calling Agent Builder berdasarkan dokumentasi lengkap di folder `~agent-builder-docs`. Ini adalah sistem multi-agent orchestrator yang berjalan di Termux (Android) atau Windows, tanpa Docker, berdiri sendiri.

## Tujuan
Membangun V1 sistem Agent Calling Agent Builder yang berjalan di Termux Ubuntu prootchroot, lengkap dengan semua komponen yang terdokumentasi, mengikuti hard constraints yang ditetapkan, dan siap dijalankan sebagai sistem orchestrator.

## Lingkungan
- OS Termux Ubuntu prootchroot (Android) atau Windows
- Tools tersedia git, python, nodejs, tmux, curl, hermes CLI
- Docker TIDAK support di Termux — jangan gunakan Docker
- Target V1 (single Agent 2, sequential, blocking) + komponen pendukung

## Hard Constraints (WAJIB TAAT)

1. Timeout 15 menit per-task — implementasi harus punya mekanisme timeout
2. Spawn + Cleanup Anti race condition — cek Agent 2 lama mati sebelum spawn baru
3. Blocking model Agent 1 tunggu Agent 2 selesai sebelum lanjut
4. Auto-stop Berhenti hanya jika checklist tujuan tercapai + tidak ada blocker + output sesuai
5. Sub-task size Pecah jadi  10 menit per sub-tugas
6. Progress tracking Via completisi sub-tugas (bukan real-time)
7. Handle output salah Review → koreksi → replay (max 2x) → escalasi
8. Failing cases TIMEOUT  CRASH  OUTPUT_MISMATCH  STUCK — implementasi wajib handle ke-4 kasus ini

## Komponen Wajib V1

### 1. SKILL.md — Orchestrator Skill
- Definisi Agent 1 behavior plan → delegate → review → decide
- 8 hard constraints (lihat docs02-conceptSKILL.md section 5b)
- Context prompt untuk Hermes CLI
- Status Selesai (sudah ada di docs, cukup copy ke project)

### 2. AGENT2_INSTRUCTION.md — Agent 2 Instruction Template
- Template instruksi yang diberikan ke Agent 2
- Template laporan terstruktur yang wajib diikuti Agent 2
- 4 failing cases [TIMEOUT], [CRASH], [OUTPUT_MISMATCH], [STUCK]
- Status Selesai (sudah ada di docs, cukup copy ke project)

### 3. status_tracker.py — Status Tracker
- Modul Python untuk track status Agent 2 idle, running, completed, failed
- Simpan status di file JSON (misal logsstatusagent_status.json)
- Fungsi `get_status()`, `set_status(status)`, `update_progress(task, progress)`
- Wajib handle ke-4 failing cases dan simpan riwayat

### 4. spawn_agent2.sh — Spawn Agent 2 via Tmux
- Script bash untuk spawn Agent 2 di tmux session
- Cek dulu Agent 2 lama masih hidup (anti race condition)
- Kirim instruksi ke Agent 2 via tmux send-keys
- Wajib handle cleanup jika Agent 2 crash

### 5. binagent-builder — CLI Wrapper
- Script bash untuk menjalankan sistem
- Command `agent-builder start` — mulai orchestrator
- Command `agent-builder status` — lihat status Agent 2
- Command `agent-builder logs` — lihat log
- Command `agent-builder kill` — kill Agent 2
- Command `agent-builder help` — tampilkan help

### 6. .env.example — Template Konfigurasi
- Berisi variabel environment yang dibutuhkan
- Termux-friendly (tidak include Docker-related vars)
- Status Selesai (sudah ada di docs, cukup copy ke project)
